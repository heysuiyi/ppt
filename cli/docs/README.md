# CLI 前端设计与执行计划

本目录维护生产 Node CLI 前端的交互目标和后续实施计划，覆盖启动、首页、输入、消息、工具、审批、面板、会话切换与退出。实现主要位于 `cli/terminal/`、`cli/commands/`；宿主位于 `cli/host/`。不是桌面 React UI 文档，也不把展示状态带入 Harness 内核。

## 当前事实与本轮边界

- 已有 inline TUI、单 stdin/raw owner、主草稿、补全、模型/能力选择、审批、真实正文预览、Node 宿主和恢复端口；不重新搭建另一套入口。
- 默认上下文只保留模型名与工作区；去除常驻厂商、工具模式、就绪和重复教学。欢迎内容从首帧延续到会话，首次正文交接时一次退入终端历史。
- 会话绑定与历史协调交接；正文/工具按公开身份更新，权威结果协调结算。用户消息改为有背景、内边距和留白的消息块，不再显示 `You:`；流式、最终与恢复历史保持一致，无色模式仍能区分角色。补全、面板、审批仍由同一输入 owner 管理，不改变持久恢复或授权含义。
- 助手 Markdown 已参考 OMP 接入语法节点渲染：标题与行内样式、引用、嵌套/任务列表、按终端宽度折行与对齐的 GFM 表格；流式、最终与恢复历史共用实现。代码块保留内容和未闭合状态，链接保留地址、HTML 仅作文字；不改变 plain/print/JSONL，无新增依赖。验证范围见执行记录第 7.10 节。
- 输入框参考 OMP：模型/路径嵌上边框、左右留白、完整闭合底边，按焦点区分边框；占位提示为低对比灰色，正文保持默认前景。正文最多六行并随光标滚动，补全在框下，secret 不回显内容或长度。显示与上下导航共享实际正文宽度，缩放和 selector 返回保留草稿与字素光标；不改变提交/取消/审批语义。验证见执行记录第 7.9 节。
- 工具卡按 OMP 完整边框/分区方式呈现目标、执行状态、统计与正文；当前支持 read/glob/grep/write/edit，各工具默认展示足量内容，不再统一限制三行。Ctrl+O 展开与翻页、Escape 收起，`/tools-output` 选择观察到的历史工具；视口缩减保留闭合边框。成功结果仅消费受认可的 `tools.<name>@1` 展示载荷，未知工具/版本不打印原始输入、结果或私有重放。最新验证范围见执行记录第 7.8 节。
- 已运行生产 `runCli`、真实 NodeHost、DPAPI/SQLite 和 loopback SDK 的 Windows TTY 场景，包括跨进程 waiting 恢复、冷配置秘密输入及切换；全量、集成和类型检查通过，具体范围见执行记录。
- 没有远程模型调用，OMP 完整 CLI 仍未运行；没有将本地受控模型速度、其他平台、复杂 IME/emoji 或用户视觉认可标为已验收。

## 文档维护规则

1. 新的 CLI 前端目标以本目录为唯一维护位置；根计划保留入口，历史终端文档保留既有实现与验收，不重复维护一份未来执行清单。
2. 所有“目标/待实施”与“已实现/已验证”分开表述。实施后同步这里、整体方案的现状和下一步计划状态，保留带范围的历史证据。
3. 变更公开契约前检查调用方，执行时迁移全部受影响路径；不长期保留别名、双入口和旧默认展示分支。
4. 本项目的审批、取消、单次激活、无隐式排队、安全输入、持久恢复和输出协议仍受仓库约定约束。借鉴 OMP 的呈现机制，不自动接入它的 steering、队列、自动重试或审批语义。
5. 真实终端观察、受控 SDK/HTTP、远程厂商和自动回归分别记录；无实际证据不标为通过。用户视觉反馈单独记录，不由测试替代。
