## Skill 与工具边界的问题

1. **柔影参考与 SVG 子集提示不完整。** `soft-rounded` 参考提供 soft-shadow，build skill 明确禁止脚本、foreignObject 等，但未在页面契约里明确提醒 `<filter>`/CSS filter 不可用。模型自行选择滤镜的实现方式，随后被验证器拒绝。建议在作者参考中说明用透明几何叠层实现阴影；无需新增流程硬锁。
2. **路线 ID 应从真实返回值选。** 模型在首次评估时自造候选 ID；回退救回了本次任务，但不是理想的选择依据。应优先使用推荐值或已返回候选，避免让模型预先猜名字。
3. **“预览通过”与“质量合格”存在距离。** 工具能证明合法 SVG 成功渲染且有当前哈希，却没有自动证明视觉质量。模型的自检准确发现了布局变化，但没有指出页脚对比度和正文缩小。适合加强看图时的少量质量检查，不适合为了本次三页强制再加载所有上游技能。
4. **不把参考路径当考勤。** 没有独立调用 ppt-review、没有再回读自己刚写的两份计划，不自动构成严重缺陷。应看最终内容是否完整、视觉是否可靠、修改是否经过当前版本预览。本次未发生版本漂移证据。
